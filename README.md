# 面積ハカルくん

iPhone のカメラまたは写真ライブラリから画像を読み込み、基準線で縮尺を設定して、皮膚病変の面積を測定する端末内処理型 Web アプリです。

## 公開URL

[面積ハカルくんを開く](https://satorumuro.github.io/hakarukun-web/)

## 主な機能

- 写真撮影・写真ライブラリからの読込み
- 画像のトリミング
- 2点の基準線と実寸（mm）による縮尺設定
- OpenCV.js の GrabCut による病変候補の抽出
- 最大連結成分の選択、穴埋め、境界の整形
- ブラシによる塗り足し・消去
- 面積（cm²）の再計算

写真と測定データはブラウザ内で処理され、サーバーには送信されません。測定値は参考値であり、診断や治療方針の決定には使用しないでください。

## ローカル実行

Node.js 22 以降が必要です。

```bash
npm ci
npm run dev
```

## GitHub Pages

`main` への push で GitHub Actions が静的ビルドを行い、GitHub Pages に公開します。
